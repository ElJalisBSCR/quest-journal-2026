# ⚔️ Quest Journal 2026

A gamified RPG quest journal for tracking your 2026 goals. Built with React + Vite.

## Deploy to Vercel (Easiest)

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click "Import Project" and select this repo
4. Click "Deploy" — done!

Your site will be live at `your-project-name.vercel.app`. Bookmark it and use it daily.

## Local Development

```bash
npm install
npm run dev
```
